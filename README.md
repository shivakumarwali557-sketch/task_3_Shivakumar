# Random Password Generator

## Project 3 - Python Programming

This project is a Random Password Generator developed using Python.

## Features

- Takes password length from the user
- Generates random passwords
- Uses uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Ensures that the password contains at least one number
- Shuffles the generated password

## Technologies Used

- Python
- random module
- string module

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python password_generator.py
